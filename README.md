# Cre8Hive Portfolio Website Prompt (Lovable)

Create a premium, modern, responsive portfolio website for **Cre8Hive**, a digital agency specializing in AI-powered development, websites, mobile apps, automation, CRM, branding, and digital growth.

## Design Direction

The website should feel like a mix of Framer, Linear, Vercel, and DesignJoy.

The design must be:

- Clean

- Premium

- Minimal

- Modern

- Fast

- Professional

- Lots of white space

- No clutter

- NO gradients anywhere

- No glassmorphism

- No neon effects

Use subtle shadows, rounded corners (12-16px), clean borders (#EAEAEA), and smooth micro-interactions.
